# 全国高校大数据平台 · 逆向工程爬虫技术设计与实现文档

本项目针对全国高校数据采集需求，突破了常规静态爬虫只能爬取无防爬站点的局限，针对国内权威平台 **“掌上高考 / 中国教育在线 (gaokao.cn)”** 核心数据网关进行了深度的 **Web / JavaScript 逆向工程**，实现了脱离浏览器环境下的高并发、高可用最新真实数据采集与系统数据库闭环集成。

---

## 一、 核心技术深度与逆向分析架构

传统静态爬虫面对现代 Web 动态防篡改网关往往失效。本项目数据采集流水线突破单纯 DOM 解析局限，采用纯 Python 原生还原了企业级 API 网关的鉴权签名算法，具备以下关键技术深度：

### 1. 核心接口采用防篡改签名鉴权 (`signsafe`)
- **防护现象**：通过抓包工具可见，所有核心数据接口（如全国高校名录、各省录取分数线）均向 `https://api.zjzw.cn/web/api/` 发送 POST 请求，必须附带 32 位 Hex 签名参数 `signsafe`。如果直接复制请求、修改参数或省略签名，服务器直接拦截并返回 `4000 验签失败`。
- **逆向定位**：
  - 在 Chrome DevTools 中分析 `https://www.gaokao.cn/school/search` 的打包构建产物；
  - 在调用栈与 `main-96d4916e.js` 打包文件中下断点跟踪，定位到未混淆前的原始签名方法 `function A(t)`；
  - 顺藤摸瓜定位到签名算法的完整链路与依赖模块。

### 2. 复合型多层加密算法还原
该平台的签名并非简单的单次 MD5，而是多层哈希与加密算法的组合：
1. **参数有序化**：将请求载荷中的全部 Key 进行 ASCII 字典序排序（`sort()`）；
2. **网关路径拼接**：动态提取网关域名（`api.zjzw.cn`）并拼接固定路由前缀 `/gkcx/api/?`；
3. **加盐 HMAC-SHA1 散列**：使用逆向提取的专有通信密钥 **`"D23ABC@#56"`** 对拼接后的参数串进行 `HMAC-SHA1` 消息鉴权计算；
4. **Base64 编码**：将 HMAC 二进制摘要转换为标准 Base64 字符串；
5. **MD5 摘要生成**：对 Base64 字符串再次执行 32 位 MD5 压缩计算，输出最终合法的 `signsafe`。

### 3. 前端对称加密体系（AES-128-CBC 备用通道）
逆向过程中还定位到了平台用于敏感设备指纹与私有参数传输的对称加密函数 `function g(t)` 与解密函数 `function p(t)`：
- **加密算法**：`AES-128-CBC`（PKCS7 Padding）
- **通信密钥 (Key)**：`CernetFIT4206Sun`
- **初始化向量 (IV)**：`XfqauTPSQHSpwJX6`

## 二、 工程模块结构

```text
crawler/
├── signer.py         # 逆向签名核心算法库 (纯 Python 实现，无 Node.js 依赖)
├── proxy_manager.py  # 免费动态代理 IP 管理器 (融合多源聚合、本地预热缓存与坏代理黑名单隔离)
├── fetcher.py        # 高可用网络抓取器 (Session 复用、智能退避重试、动态代理 IP 瞬时轮换)
├── cleaner.py        # ETL 数据清洗管道 (省份名称标准化、办学层次归一化、异常分数过滤)
├── db_loader.py      # MySQL 批量入库器 (Upsert 机制、外键关联、采集/清洗日志持久化)
├── run_crawler.py    # 一键自动化调度执行入口 (支持 --proxy 启用动态代理池)
└── README.md         # 逆向工程与技术实现文档 (本文件)
```

### 4. 免费多源动态代理池融合 (抗 IP 频控核心)
为了对抗目标教育网关的 IP 级速率限制（`code: 1069 访问太过频繁`），项目深度融合了本地轻量级动态代理池模块，并借鉴了工业级运行策略：
- **多源并发聚合**：无须常驻 Redis 或中间件，按需并发聚合 8 大免费公开源；
- **严格 HTTPS 隧道验证**：对候选代理真实验证目标 API 必须的 HTTPS `CONNECT` 隧道能力与出口 IP；
- **本地预热缓存 (`proxies_cache.json`)**：验证通过的健康代理持久化至本地缓存，下次启动秒级直出；
- **故障黑名单隔离与瞬时轮换**：代理请求超时或遭遇频控时，毫秒级将其加入坏代理隔离冷却池，并自动切换下一个健康出口 IP，实现高可用自愈。

## 三、 运行与使用

### 1. 依赖环境
```bash
pip install requests pymysql pandas
```

### 2. 一键启动数据采集
在项目根目录或 `crawler/` 目录下执行：
```bash
python crawler/run_crawler.py
```
执行过程中程序将自动：
1. 逆向计算合法签名并批量抓取全国 150+ 所全国高校详细名录；
2. 清洗数据并写入本地 MySQL `univ_bigdata_db.university` 表；
3. 批量抓取代表院校的 2023-2024 年最新录取分数线，写入 `enrollment` 表；
4. 向 `data_collect_log` 和 `data_clean_log` 写入真实产生的操作日志。

## 四、 核心架构设计与工程问答 (Architecture Q&A)

> **Q1：你们项目的爬虫和普通爬虫有什么区别？**  
> **A**：普通爬虫通常只能抓取服务端直出的无防爬静态网页；而本项目针对的是大型教育门户的前后端分离 API。该接口采用了前端 Webpack 打包混淆和 `signsafe` 动态参数签名机制。我们通过 Chrome DevTools 断点跟踪调用栈，定位出签名生成逻辑，并在 Python 端实现了纯算法还原，从而以最高效的协议直连方式采集到了最新的结构化官方数据。

> **Q2：如果目标网站更新了签名密钥怎么办？**  
> **A**：我们遵循模块化与高内聚设计，将加密逻辑独立封装在 `signer.py` 中。如遇前端盐值或拼接规则更新，只需在逆向分析后微调 `signer.py` 中的常量或拼接步骤，上层的抓取流控、清洗管道与数据库入库逻辑完全无需改动。
